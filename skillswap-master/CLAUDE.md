# CLAUDE.md

Guidance for Claude Code (and humans) working in this repository.

## What this is

**SkillSwap** — a full-stack community skill-sharing & micro-volunteering
platform. Users list what they can teach and what they want to learn; the app
matches them, handles scheduling, and settles every exchange through a
**community credit system** (no money — teaching earns credits, learning spends
them). Single Next.js codebase: frontend, routing, and backend API routes all
live here, so there is **no separate backend service**.

## Stack

| Concern         | Choice                        | Notes                                                    |
| --------------- | ----------------------------- | -------------------------------------------------------- |
| Framework       | Next.js 14 (App Router)       | React + routing + API routes in one project              |
| Language        | TypeScript                    | Strict mode via `tsconfig.json`                          |
| UI runtime      | React 18                      | Pinned to 18 for `@tremor/react` compatibility           |
| Styling         | Tailwind CSS v3               | Custom `brand`/`accent` palette + Tremor theme           |
| Components      | Tremor (`@tremor/react` v3)   | Reserved for stats/leaderboard charts                    |
| Database        | **`node:sqlite`** (built-in)  | Node 24's built-in SQLite — no native build, no deps     |
| Local AI        | LM Studio (Gemma) — optional  | `http://127.0.0.1:1234` for semantic search; fails soft  |
| Package manager | npm                           | `package-lock.json` is committed                         |

> **Why `node:sqlite`, not `better-sqlite3`?** `better-sqlite3` needs a C++
> toolchain (Visual Studio Build Tools) that isn't installed here, so it fails to
> compile. Node 24 ships a built-in synchronous SQLite module (`node:sqlite`)
> that gives us real SQL with zero native compilation. Types are declared in
> [types/node-sqlite.d.ts](types/node-sqlite.d.ts) (since `@types/node` ^20
> predates the module).

> **Version pinning matters.** `@tremor/react` v3 targets React 18 + Tailwind v3.
> Do not upgrade to React 19 / Next 15+ / Tailwind v4 without migrating off
> classic Tremor.

## Architecture

### Data layer (`lib/`)
- [lib/db.ts](lib/db.ts) — opens `data/skillswap.db`, runs `CREATE TABLE IF NOT
  EXISTS` migrations, seeds two demo users. **Connection is lazy** (a Proxy opens
  it on first query, never at import) so `next build`'s parallel workers don't
  fight over the file ("database is locked").
- [lib/crypto.ts](lib/crypto.ts) — scrypt password hashing + session tokens.
- [lib/auth.ts](lib/auth.ts) — `getCurrentUser()` / `requireUser()` (reads the
  `ss_session` httpOnly cookie), `createSession`, `destroySession`.
- [lib/ai.ts](lib/ai.ts) — defensive LM Studio client (`expandTerms`,
  `expandQuery`); returns `[]` if the server is down.
- `lib/repos/*.ts` — typed data access, one module per concern: `users`,
  `credits`, `courses`, `requests` (the exchange engine), `materials`,
  `reviews`, `stats`.

### Credit rules (important)
Everyone starts with **5** credits; a course costs **1–4**. Credits are held in
**escrow on accept** and **released on completion**:
- `availableCredits = balance − heldCredits` (held = escrow on requests in
  `accepted`/`confirmed` status). See [lib/repos/credits.ts](lib/repos/credits.ts).
- Learn/Join is blocked when `available < cost`.
- On `complete`: teacher `+cost`, student `−cost`, course popularity `+1`.

### Exchange lifecycle (status machine)
`pending → accepted → confirmed → completed` (or `rejected`). Driven by
`PATCH /api/requests/[id]` with an `action`. See
[lib/repos/requests.ts](lib/repos/requests.ts) and the orchestrator UI at
[app/requests/[id]/page.tsx](app/requests/[id]/page.tsx):
1. Student `POST /api/requests` → **pending**.
2. Teacher `accept` (sets weekly availability, session length, expected end,
   rules; escrows credits) → **accepted**.
3. Student `confirm` (picks a subset of the teacher's slots) → **confirmed**;
   a `timetable` is generated by expanding the chosen weekly slots to the
   expected-end date.
4. Teacher shares a `meetlink`; the student's "Join class" button activates.
5. Teacher uploads a PDF; the student's reading time is tracked with a simple
   **open/close timer** (`/api/materials/[id]/track`).
6. Either party `complete`s → credits released.
Reviews (1–5 + text) can be left any time an exchange exists, either direction.

### Real-time-ish updates
No sockets — client **polls every ~4s** via `usePoll` in
[components/hooks.ts](components/hooks.ts) on the request inbox, request detail,
and materials list.

## Conventions
- **Import alias:** `@/` maps to the project root.
- **Server vs client:** App Router files are Server Components by default. Add
  `"use client"` for hooks/handlers. Any route touching the DB sets
  `export const runtime = "nodejs"`.
- **Never import `lib/db` or `lib/repos/*` into a client component** — they pull
  in `node:sqlite`. Client components use plain shapes from
  [components/request/types.ts](components/request/types.ts) instead.
- **Data access goes through `lib/repos/*`**, not raw SQL in routes.

## Tremor usage
Import from the single package; styling depends on
[tailwind.config.ts](tailwind.config.ts) (content globs incl.
`./node_modules/@tremor/**`, the `tremor`/`dark-tremor` theme, the color
`safelist`, and the `@headlessui/tailwindcss` + `@tailwindcss/forms` plugins). If
Tremor renders unstyled, one of those is missing.

## Gotchas
- **Node 18+ required** for the build; **`node:sqlite` needs Node ≥ 22.5**
  (developed on Node 24). It prints an `ExperimentalWarning` at runtime — that's
  expected, not an error.
- **Reset the database:** delete the `data/` folder; it's recreated and reseeded
  (demo users `priya@demo.dev` / `arjun@demo.dev`, password `password`) on next
  request.
- **Demo two users** by logging in as the two demo accounts in a normal tab and
  an incognito window against the same server.
- **Folder name** is `Hackathon` (capital H) — invalid as an npm name, so
  `package.json` is `hackathon-dashboard`.
- **LM Studio is optional.** With it off, Explore/Match fall back to keyword
  matching; the "AI" toggles simply show a notice.
